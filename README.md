# PACE AI

A native habit and running companion. Dark athletic UI, lime accent, on-device accounts, GPS runs, and a coach that speaks from the workout in front of you.

Open the Expo Go preview from `wren-preview.json` (SDK 58, channel `preview`).

```bash
npm install
npx expo start
```

`API_KEY` is the Mapbox token. Copy `.env.example` to `.env` and leave it empty unless you have a key. The app reads `process.env.API_KEY`. Do not commit the value.
